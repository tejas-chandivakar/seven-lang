Install SEVEN

Get up and running in under a minute.

Windows Quick Start

Step 1 — Clone and build 
git clone https://github.com/tejas-chandivakar/seven-lang.git
cd seven-lang
install-windows.bat
Step 2 — Add to PATH (one-time) 
setx PATH "%PATH%;C:\path\to\seven-lang\build;C:\Program Files\LLVM\bin"
Step 3 — Use SEVEN 
seven-llvm run hello.seven
seven-llvm build hello.seven -o hello.exe
hello.exe

install-windows.bat automatically installs LLVM and CMake via winget, then builds the compiler.

Manual Setup

PowerShell — Install dependencies 
winget install LLVM.LLVM
winget install Kitware.CMake
Build 
build.bat

Daily Usage

Command Prompt / PowerShell 
!! Run a program directly
seven-llvm run myprogram.seven

!! Build a standalone .exe
seven-llvm build myprogram.seven -o myprogram.exe
myprogram.exe

!! Check version
seven-llvm --version

!! See LLVM IR output
seven-llvm build myprogram.seven --emit-ir

VS Code Extension

Syntax highlighting and code snippets for .seven files.

cd editor\vscode
code --install-extension .

Requirements

Linux (NASM backend)

NASM + GNU ld + make

Linux (LLVM backend)

LLVM 21 + Clang + GCC + make

Windows (Native)

LLVM + CMake

Windows (WSL)

WSL 2 + Linux requirements

1. Install Dependencies

Ubuntu / Debian 
sudo apt update
sudo apt install nasm binutils make
Fedora / RHEL 
sudo dnf install nasm binutils make
Arch Linux 
sudo pacman -S nasm binutils make

2. Build from Source

Terminal 
git clone https://github.com/tejas-chandivakar/seven-lang.git
cd seven-lang
make

This builds the compiler at build/seven.

3. Verify Installation

Terminal 
./build/seven version
SEVEN v1.4.0

4. Write Your First Program

hello.seven 
show "Hello, World!"
Compile and run 
./build/seven build hello.seven
./hello
Hello, World!
NEW in v1.4

LLVM Backend

33x faster compilation with native LLVM. The LLVM backend is now the default on all platforms.

Build LLVM backend (Linux) 
sudo apt install llvm-21-dev clang-21 gcc
make llvm
Usage 
./build/seven-llvm run hello.seven
./build/seven-llvm build hello.seven -o hello
Compiled: hello
