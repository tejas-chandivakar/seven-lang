SEVEN Language Documentation

Version 0.7 — Phase 7 Complete

SEVEN is a compiled, dynamically-typed programming language designed for assembly-level speed with Python-level simplicity.

  • File extensions: .seven (primary), .sev, .sv7, .s7
  • Compile: seven build main.seven
  • Run directly: seven run main.seven

Design Principles

Speed first — direct assembly, no VM, no GC
Human-readable — show, ask, repeat, each
Explicit blocks — end closes every block
One way — no +=, no ternary, small grammar

Mode System

Declare mode on the first line. Default is hybrid.

mode hybrid       !! default — push(list, x)
mode natural      !! English — add x to list
Operationmode hybridmode natural
Appendpush(list, x)add x to list
Removeremove(list, i)remove i from list
Insertinsert(list, i, x)insert x at i in list
Poppop(list)pop from list

Input / Output

show "Hello!"              !! print + newline
show "a", "b", "c"         !! prints: a b c
err "warning!"             !! print to stderr

name = ask "Name: "         !! prompt + read line
pass = secret "Password: "  !! hidden input

write "file.txt", data    !! write to file
text = read "file.txt"     !! read from file

Control Flow

if / elif / else

if score atleast 90
    show "A"
elif score atleast 80
    show "B"
else
    show "F"
end

while

while x below 10
    show x
    x = x + 1
end

repeat

repeat 5 times
    show "Hello"
end

repeat 10 times as i
    show i
end

each

each list as item         !! value only
    show item
end

each list as i, item      !! index + value
    show i + ": " + item
end

skip = continue, stop = break. x in list tests membership.

Functions

func greet(name)
    show "Hello, " + name
end

func add(a, b)
    return a + b
end

!! Variadic parameters
func print_all(many items)
    each items as item
        show item
    end
end

many collects remaining args into an array. Must be the last parameter.

Strings

s = "Hello, World"
show len(s)              !! 12

show s.lower()           !! hello, world
show s.contains("World") !! 1 (true)

!! Interpolation

Arrays

nums = [10, 20, 30]
show nums[0]              !! 10
show nums[-1]             !! 30 (last element)

push(nums, 40)
sort(nums)
show join(nums, ", ")    !! 10, 20, 30, 40
show len(nums)            !! 4

Developer Tools

REPL — tools/repl

Interactive shell. Commands: .help .clear .undo .show .exit

Formatter — tools/fmt

Auto-indent code. Use --check for CI (exits 1 if changes needed), --indent N for custom width.

Linter — tools/lint

Static analysis: unmatched blocks, style issues (trailing whitespace, tabs), unused variables.

Profiler — tools/profile

Measures compilation, assembly, and execution time over N runs. Reports min/max/avg.

VS Code Extension — editor/vscode

Syntax highlighting for all keywords and builtins. 12 code snippets. Supports .seven, .sev, .sv7, .s7.

Runtime Model

No garbage collection — 16MB bump arena freed on exit
Stack-based evaluation — expressions in generated assembly
All variables are global — stored as BSS slots
64-bit integers — strings and arrays are heap pointers
Direct x86-64 — compiles to NASM assembly, linked with GNU ld
