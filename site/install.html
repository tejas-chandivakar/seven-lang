Install SEVEN

Get up and running in under a minute.

Requirements

Platform

Linux x86-64

Assembler

NASM

Linker

GNU ld

1. Install Dependencies

Ubuntu / Debian 
sudo apt update
sudo apt install nasm binutils make
Fedora / RHEL 
sudo dnf install nasm binutils make
Arch Linux 
sudo pacman -S nasm binutils make

2. Build from Source

Terminal 
git clone https://github.com/tejas-chandivakar/seven-lang.git
cd seven-lang
make

This builds the compiler at build/seven.

3. Verify Installation

Terminal 
./build/seven version
SEVEN v1.2.0

4. Write Your First Program

hello.seven 
show "Hello, World!"
Compile and run 
./build/seven build hello.seven
./hello
Hello, World!

Windows (via WSL)

SEVEN runs on Windows through the Windows Subsystem for Linux.

PowerShell (one-time setup) 
wsl --install

After WSL is set up, open it and follow the Linux install steps above.

VS Code Extension

Syntax highlighting and code snippets for SEVEN files.

cd editor/vscode
code --install-extension .

Supports .seven, .sev, .sv7, .s7 file extensions.
