SEVEN is a compiled programming language that generates native x86-64 assembly. No VM. No garbage collector. No runtime overhead. Just fast, readable code.

Get Started Read the Docs

!! Loops are simple
repeat 5 times
    show "SEVEN is fast!"
end

Why SEVEN?

Built from scratch in x86-64 Assembly. Every feature designed for speed and clarity.

32x Faster than Python

Compiles directly to native x86-64 machine code. No interpreter, no virtual machine, no garbage collector overhead.

Human-Readable Syntax

English-like keywords: show, ask, repeat, use, each...as. Code reads like plain English.

Self-Hosted Compiler

SEVEN compiles itself. Full 5-stage pipeline (lexer → parser → analyzer → IR → codegen) written in SEVEN with use imports.

48 Built-in Functions

Rich standard library: strings, math, arrays, file I/O, OS system calls, assert. Plus 11 string methods.

Package Manager

spm install — full package manager with init, install, publish, lock files. Plus REPL, formatter, linter, and VS Code extension.

Built-in Testing

assert(cond, msg) builtin + test runner that auto-discovers and runs test files with colored output.

Code Examples

Clean, expressive syntax for real-world tasks

arrays.seven 
!! Create and manipulate arrays
nums = [10, 20, 30, 40, 50]
push(nums, 60)
sort(nums)

each nums as i, val
    show "[" + i + "] = " + val
end

show "Sum: " + sum(nums)
show "Unique: " + unique(nums)
functions.seven 
!! Define reusable functions
func greet(name)
    show "Hello, " + name + "!"
end

func factorial(n)
    if n below 2
        return 1
    end
    return n * factorial(n - 1)
end

greet("World")
show "10! = " + factorial(10)
file_io.seven 
!! File operations
write "notes.txt", "Hello from SEVEN!"
append("notes.txt", "\nLine two")

if exists("notes.txt")
    content = read "notes.txt"
    show content

    all_lines = lines("notes.txt")
    each all_lines as line
        show "> " + line
    end
end

delete("notes.txt")
loops.seven 
!! Repeat N times
repeat 5 times as i
    show "iteration " + i
end

!! While loop
x = 0
while x below 5
    show "x = " + x
    x = x + 1
end

!! Each with skip and stop
nums = [1, 2, 3, 4, 5]
each nums as n
    if n is 3
        skip
    end
    show n
end
errors.seven 
!! Try-catch error handling
try
    result = 100 / 0
    show result
catch e
    err "Caught: " + e
done

!! Throw custom errors
func divide(a, b)
    if b is 0
        error "Cannot divide by zero"
    end
    return a / b
end

show divide(10, 3)
compile.seven 
!! Import modules with use
use "src/self/lexer.seven"
use "src/self/parser.seven"
use "src/self/codegen.seven"

!! All functions are now available
source = "show 42" + chr(10)
lex_run(source)
stmts = parse_all()
codegen_generate(stmts)

show "Compilation complete!"
