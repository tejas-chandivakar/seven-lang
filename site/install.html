Install SEVEN

Get up and running in under a minute.

Windows Quick Start

Step 1 — Clone and build 
git clone https://github.com/tejas-chandivakar/seven-lang.git
cd seven-lang
install-windows.bat
Step 2 — Add to PATH (one-time) 
setx PATH "%PATH%;C:\path\to\seven-lang\build;C:\Program Files\LLVM\bin"
Step 3 — Use SEVEN 
seven run hello.seven
seven build hello.seven -o hello.exe
hello.exe

install-windows.bat automatically installs LLVM and CMake via winget, then builds the compiler.

Manual Setup

PowerShell — Install dependencies 
winget install LLVM.LLVM
winget install Kitware.CMake
Build 
build.bat

Daily Usage

Command Prompt / PowerShell 
!! Run a program directly
seven run myprogram.seven

!! Build a standalone .exe
seven build myprogram.seven -o myprogram.exe
myprogram.exe

!! Check version
seven --version

!! See LLVM IR output
seven build myprogram.seven --emit-ir

Optimization Flags

SEVEN uses LLVM optimization passes. Default is -O2.

Command Prompt / PowerShell 
!! Default optimization (O2)
seven build app.seven -o app.exe

!! Maximum optimization
seven build app.seven -O3 -o app.exe

!! No optimization (faster compile)
seven build app.seven -O0 -o app.exe
NEW

Run in the Browser (WebAssembly)

Compile to WebAssembly using WSL and run in any browser.

WSL Terminal 
# Install linker (one-time)
sudo apt install lld-21

# Compile to WebAssembly
./build/seven build app.seven --target wasm -o build/app

# Serve and open in browser
python3 -m http.server 8000 --directory build

Open http://localhost:8000/app.html in your browser. The compiler generates both .wasm and .html automatically.

Requirements

Linux (NASM backend)

NASM + GNU ld + make

Linux (LLVM backend)

LLVM 21 + Clang + GCC + make

Windows (Native)

LLVM + CMake

Windows (WSL)

WSL 2 + Linux requirements

1. Install Dependencies

Ubuntu / Debian 
sudo apt update
sudo apt install nasm binutils make
Fedora / RHEL 
sudo dnf install nasm binutils make
Arch Linux 
sudo pacman -S nasm binutils make

2. Build from Source

Terminal 
git clone https://github.com/tejas-chandivakar/seven-lang.git
cd seven-lang
make

This builds the compiler at build/seven.

3. Verify Installation

Terminal 
./build/seven version
SEVEN v1.4.0

4. Write Your First Program

hello.seven 
show "Hello, World!"
Compile and run 
./build/seven build hello.seven
./hello
Hello, World!

Build LLVM backend (Linux) 
sudo apt install llvm-21-dev clang-21 gcc
make llvm
Usage 
./build/seven run hello.seven
./build/seven build hello.seven -o hello
Compiled: hello

Optimization Flags

SEVEN uses LLVM optimization passes. Default is -O2.

Terminal 
!! Default optimization (O2)
./build/seven build app.seven

!! Maximum optimization
./build/seven build app.seven -O3

!! No optimization (faster compile, slower output)
./build/seven build app.seven -O0
FlagDescription
-O0No optimization — fastest compile time
-O1Basic optimizations
-O2Recommended (default) — good balance of speed
-O3Aggressive — maximum runtime speed
NEW

Run in the Browser (WebAssembly)

Compile any SEVEN program to WebAssembly and run it in any modern browser. No plugins needed.

Step 1 — Install wasm-ld (one-time) 
sudo apt install lld-21
Step 2 — Compile to WebAssembly 
./build/seven build app.seven --target wasm -o build/app
Step 3 — Serve and open in browser 
python3 -m http.server 8000 --directory build
# Open http://localhost:8000/app.html in your browser

The compiler generates both app.wasm and app.html (with JavaScript bridge). Just open the HTML file to see output.
